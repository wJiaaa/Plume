# 计划模式：怎么进出、开着时能做什么、批准计划后会怎样

计划模式让 Plume 先只读地调查，交一份计划给你审，批准之前不改任何东西。它记在当前对话上，不影响别的对话，也和权限档（包括完全访问）互不影响。

## 怎么进、怎么出

- 点输入框工具栏里的计划模式按钮（列表图标，悬停提示「进入计划模式：先调查、交一份计划，批准后再动手」）。开着时按钮变成强调色，带「计划模式」字样；再点一下退出。
- 或在输入框里发 `/plan`：不带内容就是开关切换；带内容（`/plan 把登录改成 OAuth`）会先进计划模式，再把后半句当普通消息发出去。
- 需要一个已经开始的对话。空白新对话里先发一句话，否则会提示「计划模式记在对话上，先发一句话开始这个对话。」
- 开关立刻生效：Plume 正在跑的这一轮里打开，下一次改文件的调用就会被拦住；中途关掉则立刻放开。

## 开着时能做什么

- 能做：读文件、搜索、列目录、查符号、查网页、开浏览器、调用 MCP 工具、给别的对话发消息、更新任务清单、向你提问、派子智能体。
- 不能做：编辑或新建文件（`write`、`edit`）、`lsp` 的重命名。它们会被直接拒绝，Plume 会被告知先交计划。
- 终端命令照常能跑，但一律在只读沙箱里执行：除 `/dev/null` 外写不了任何文件，这台机器没有沙箱时拒绝运行；需要提权离开沙箱的一律拒绝。
- 派出去的子智能体同样受这些限制。
- 任务很小时，Plume 会交一份只有一步的计划。

## 审批计划

调查完后 Plume 会弹出一张「审批计划」卡片，内容是有序的步骤（每步写明涉及的文件）、风险和还没确定的地方。完全访问或「总是允许」都不会替你批准，必须你自己选：

- 「批准，开始执行」：计划模式立刻关闭，同一轮里所有工具恢复可用，计划的步骤变成任务清单，Plume 从第一步开始做。
- 「要改」，或直接写下你的意见：意见交回给 Plume，计划模式保持开启，它改完再交一次。
- 没有选也没写意见（比如卡片失效）：这一轮停下，计划模式保持开启，等你说下一句。

批准过的计划在对话被压缩后也会保留，Plume 会继续按它执行，除非你让它重新规划。
