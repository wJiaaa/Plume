# ADR-0056：撤回和编辑重发可以连同文件一起撤，全有或全无

- 状态：已采纳
- 日期：2026-10-23
- 相关：core `src/tools/file-changes.ts`（`undoProblems`、`undoFileChangeBatches`）；desktop
  `electron/session/revert-files.ts`、`electron/session/session-hub.ts`（`revertSessionMessage`）、
  `electron/session/delivery-record.ts`（`recordedChanges`）、`src/features/conversation/files-back.tsx`
  （`RevertAction.tsx`、`UserMessage.tsx` 共用）；契约 `agent.revertPlan`、`agent.revertMessage` 与 `agent.editMessage` 的 `files`；测试 `desktop/test/revert-files.test.ts`、
  `desktop/test/ui/revert-files-dialog.test.ts`

## 背景

「撤回并重新编辑」只截对话。被截掉的那几轮改过的文件原样留在磁盘上，重问时模型以为回到了这句话之前，
读到的代码却已经被「不存在的那几轮」改过。文件改动本来就有记录（每轮交付卡片上的「撤销」用的就是它），
只是撤回没用上。

几个开源 agent 的做法（2026-10 读的源码）：

- **ZCode**：对话 / 文件 / 都撤三选一。新路径逐个文件比对 sha256，有一个被外部改过就一个都不写，写到一半
  失败回滚；先写文件，成功后才截对话。命令改的不记录，「都撤」遇到就整体拒绝。
- **qwen-code**：`/rewind` 三选一，先给出 `+N −M`。本地恢复直接覆盖，别的会话写进同一文件的东西会被吞掉；
  hosted 模式发现外部改动则整体拒绝。
- **deepseek-harness**：没有撤回，只记录不恢复。

三家都没有做三方合并，也没有多会话隔离。

## 决定

1. **撤回时可选连同文件一起撤。** 主进程先演算（`agent.revertPlan`），确认框列出被截掉那几轮改过的每个
   文件和 `+N −M`；人选「撤回对话和文件」或「只撤回对话」。没碰过文件的撤回照旧：最后一条直接撤，更早的问一句。
2. **全有或全无。** 一个文件之后被别的会话或人改过、中途被别处插过一手、改动来自命令、不在项目内，或者
   有改动没记下来（`changeWarning`、快照读不出来），就只剩「只撤回对话」，列出是哪个、为什么。只拿回一部分，
   代码会停在一个从没存在过的中间状态，比不拿回更糟。
3. **被别人改过的不覆盖、不合并。** 同 ZCode 新路径，不学 qwen-code 本地那样覆盖。演算和真正执行走同一个
   `prepareUndo`，确认框说能撤的就是撤销自己此刻的回答。
4. **先文件后对话。** 文件写不回去整件不做，对话也不截；写到一半失败由 `undoFileChangeBatches` 把已写的退回去。
5. **另一个会话在跑也放行。** 写之前 `replaceRecorded` 再比一次 ino/mtime/内容；那边编辑工具会因「读过之后
   文件变了」要求重读，不会照旧内容把撤掉的写回来。
6. **编辑并重新发送同样问。** 它和撤回做的是同一个截断（ZCode 在编辑最后一条时也给「对话 + 文件重置」）：
   提交编辑时那几轮碰过文件，就弹同一个框，「退回文件并发送」或「只重新发送」；取消回到编辑框，改好的字还在。
   主进程在 `editAndResend` 之前先写回文件，写不回去就不截、不重发。
7. **只有最后一条能编辑**，同 ZCode。改一条更早的话，等于把之后几轮连同它们改过的文件一起作废，这件事交给
   撤回。更早的消息上铅笔照旧在，置灰并说明「只能编辑最后一条消息」。只拦在按钮上：「重试」也走编辑重发，
   它往前找发起那一轮的消息，主进程不按位置拒绝。
8. **写回之后叫改动统计和 Git 面板重读**（`touchWorkingTree`）：它们只在一轮运行时轮询，闲着时退回的文件
   不叫一声，输入框上那枚 `+N −M` 会一直停在撤回之前。

## 没做的

- **三方合并**：多个会话改同一个文件时，这次一律走「只撤回对话」。要救回这一类，可以对「之后被改过」的
  文件试 `git merge-file`，合得干净才算可撤，全有或全无不变。
- **子代理改的文件**：它写文件的工具结果在子代理自己的转录里（记在主会话日志的事件中），不在主会话的消息里，
  撤回的清单只读消息，所以列不出来（交付卡片也一样）。
- **Git 仓库外命令改的文件**：没有记录，看不到也撤不了。
